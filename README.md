# Banco Caixa Universal – Sistema Bancário em Python (CLI)

Projeto desenvolvido em **Python** simulando um sistema bancário simples via terminal (CLI), com foco em lógica de programação, organização de funções e controle de fluxo.

## 📌 Descrição
A aplicação simula a experiência inicial de um cliente em um banco, permitindo verificar se o usuário já possui conta, realizar cadastro e acessar um menu inicial com opções bancárias. O projeto foi criado com o objetivo de praticar conceitos fundamentais da linguagem Python e estruturar um sistema simples baseado em funções.

## 🛠️ Tecnologias Utilizadas
- Python 3
- Entrada e saída de dados (`input` / `print`)
- Estruturas condicionais
- Funções
- Controle de fluxo

## ⚙️ Funcionalidades
- Verificação de usuário existente
- Cadastro de novo cliente
- Menu inicial com opções bancárias
- Encerramento seguro do programa

## 📚 Objetivo do Projeto
- Praticar lógica de programação
- Estruturar um programa em funções
- Trabalhar com decisões condicionais
- Simular regras básicas de um sistema real
- Evoluir gradualmente para um sistema mais completo
